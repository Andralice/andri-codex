# Andri Android

通过 SSH 操作 82 上 Codex 的 Andri Android 原生客户端，当前源码版本为 0.1.93（versionCode 94），最低 Android 8.0。

## 安装和连接

1. 安装 app/build/outputs/apk/debug/app-debug.apk。
2. 将已授权访问 82 的 SSH 私钥导入应用。不要选择 .pub 公钥；加密私钥还需要输入口令。
3. 默认地址 82.156.142.57:22，用户名 ubuntu。工作目录填写服务器上的绝对路径。
4. 点击连接后，新建或打开对话，用自然语言发送任务。

首次成功连接后，再次打开应用会使用已加密保存的私钥自动重连，并恢复上次打开的对话。返回对话列表不会清除这个记录。连接期间显示 SSH、身份验证、Codex 握手等具体阶段，可随时取消或打开历史版本；单次连接最多等待 45 秒，失败后返回可重试的页面。连接失败后可在连接页修改配置。主动选择“断开服务器”会停止自动重连，直到再次手动连接成功。

连接期间由 Android 前台服务和页面共享进程级会话，页面关闭或重建不会停止后台重连。服务通过带超时并持续续期的 CPU 唤醒锁维持锁屏后的心跳；监测默认网络切换，并在重连失败后持续退避重试。系统重建服务时会从加密存储恢复连接配置。回到应用时复用仍有效的连接并同步状态。主动断开或取消连接会停止服务、重试和唤醒锁。首次连接时 Android 13 及以上会请求通知权限。

待发布源码新增运行会话的持续补载：连接有效时由服务心跳约每 30 秒读取完整分页列表，优先串行加载正在运行和上次运行但尚未补载的会话，再预加载最近 5 条。加载期间新发现的会话会合入队列；失败保留恢复记录，在后续扫描重试。待恢复 ID 和上次离开时的运行 ID 分开持久保存，不受聊天缓存条数限制；即使后台已补载完成、随后进程被回收，重新打开仍会恢复上次离开时运行的会话。待补载队列在会话结束后读取到新快照才清除，归档或完整列表已不可见的记录移除。网关只读补齐其他后端的实时运行状态，不接管其会话；可选后端查询使用短超时，故障时保留原列表。本项未发布，手机后台、锁屏、Doze 和进程回收后的实际恢复仍需设备验收。

“更多 → 后台连接设置”（连接页也有入口）可以查看系统电池优化状态并打开设置。建议为 Andri 允许后台运行、不优化电池，并按手机厂商要求开启自启动。持续连接会增加耗电；前台服务和唤醒锁不能绕过 Doze 的全部网络限制，Android 仍可能因系统策略、断网或进程被强制停止而中断连接。系统强行停止后的恢复时间由系统决定；用户手动强制停止后需要重新打开应用。

连接后从服务器的 `model/list` 动态读取可见模型；读取失败时回退到 gpt-6-luna 和 gpt-6.1-sol。自动重连中的临时网络故障使用顶部连接图标显示恢复状态，手动连接失败及自动连接中的配置、认证错误继续显示错误；图标可用于重连或重新同步。

## 服务器连接

客户端在 SSH exec 通道内运行：

    codex app-server proxy --sock /home/ubuntu/.codex/mobile-control/app-server.sock

这个通道承载 WebSocket 握手和消息帧。不能把 proxy 当作逐行 JSON 通道。

82 上的 codex-mobile.service 使用 Ubuntu 用户运行 Codex。启动脚本读取已有的 /home/ubuntu/.codex/wyy22.env，服务会自动启动并在故障后重启。该密钥文件保持在服务器，未打包到 APK。服务通过权限为 700 的目录中的本地 socket 接受连接。

应用固定验证当前 82 的 Ed25519 主机密钥，并包含 Android 上处理该算法所需的加密实现。手机私钥使用 Android Keystore 和加密偏好设置保存，禁用云备份及设备迁移。

## 当前功能

- 项目名称与工作区使用同一份会话执行设置，优先使用当前设置，避免旧记录导致已指定项目仍显示“未指定项目”；切换对话时工作区按所属会话读取目录。
- 工作区与对话列表页面整理了标签栏、列表标题、会话行和文件行的层级与分隔样式；任务工作区增加明确的关闭入口，普通图片路径显示为可展开的图片附件卡片，可预览、复制路径并保留原有图片链接行为。
- 工作区按会话和项目保存当前标签、文件目录、预览返回栈、浏览器地址与滚动位置；切换对话或重启应用后可恢复对应工作区，项目目录边界不会串到其他项目。
- AI 可检查和操作手机工作区 WebView 中的网页：读取标题、正文、控件、视口和 Console/HTTP 错误，并截图、点击、填写、按键、滚动、刷新和返回。AI 可先打开网页；其他对话请求控制工作区时会提示切换。此功能不连接电脑 Chrome/F12 标签。
- 工作区采用浏览器式多标签，可重复打开同类内容并独立保留目录、网页、Git 视图和预览；手机端默认折叠标签栏，起始页提供搜索/网址输入和精简入口，颜色使用浅米背景、米色消息气泡与香槟米按钮点缀。
- 工作区增加受限远程终端入口，命令从当前项目目录执行并限制运行时长与回显大小；完整交互预览保存在 `codex/previews/andri-list-status-preview.html`。
- 工作区 Git 改动支持未提交改动、提交历史分页和单次提交差异，按文件分组显示增删统计，支持中文路径、暂存状态、合并提交首父差异和展开复制。
- 工作区媒体页从已加载对话及更早历史中发现图片和视频，支持远程、工作区、大文件区及内嵌图片，显示缩略图、缓存状态和下载到手机；缓存与下载失败可重试，媒体范围和文件大小继续受限制。
- 媒体页的视频下载直接保存到手机系统相册的 Andri 文件夹，下载行与系统通知显示阶段、进度、大小和速度。持久后台任务在网络中断、进程重建及设备重启后由系统恢复，固定断点与相册位置一并保留；系统强制停止后需重新打开应用。Android 10 及以上下载完整后才发布相册视频，旧系统按需申请存储权限；确定不可恢复的失败会清理未完成相册条目，图片仍使用系统文件保存位置选择器。来源变化会重新下载，HTTPS 续传依赖服务器支持范围请求和可靠来源校验；已完成缓存可清理，活动任务和未完成断点保留。
- 聊天中的可视化引用可打开工作区 HTML 交互预览，HTML/HTM 文件支持网页与源码模式切换；完整网页保留原结构，HTML 片段配套渲染样式和交互脚本。HTML 全文读取限制为 8 MB，同目录资源通过 SSH 读取；部分图标和浮层组件依赖 HTTPS 外部脚本。
- 普通文字中的工作区或大文件区图片路径可显示为紧凑的图片附件链接并预览，保留现有工作区路径边界。

- 使用选定的短发少女头像作为桌面图标，提供多分辨率与安卓自适应图标资源。
- 新建、恢复、列出对话，并支持对话列表分页；历史按最近 30 回合加载，可继续读取更早消息。
- 聊天页可打开 Codex 会话侧栏，搜索并切换已有对话或新建对话；侧栏对话直接使用 app-server 原生 thread。
- 聊天内容区域右滑打开会话侧栏，不限于屏幕左侧边缘；空白聊天页也支持右滑打开侧栏。横向导航阈值调整为 42 dp，可从可点击内容上起滑；点击、纵向滚动、多指缩放和长按选择继续由原控件处理。聊天左滑打开工作区，工作区右滑返回聊天。
- 多个对话同时执行，按消息 ID 分别接收流式回复。
- 对话运行期间可继续写消息并提交到 Codex 原生队列；由 Codex 在当前任务后按队列执行，队列状态从服务器同步并支持移除。
- 进入对话默认显示底部最新消息；向上翻阅历史时不强行滚回底部，顶部仍可加载更早消息。
- 命令/文件/权限审批队列，以及工具提出的问题。待处理请求可稍后处理，保留回答草稿；通过菜单或当前对话提示重新打开，收起窗口不会批准或拒绝请求。
- 聊天输入区默认展开，可收起为底部圆形按钮，按实际控件高度为消息保留阅读空间；附件与引用按数量折叠管理，手机图片带缩略图，运行中提供停止与排队入口。编辑时不再强制把光标移动到末尾。
- 聊天菜单可通过 SSH/SFTP 浏览服务器目录，并为当前对话选择工作区、请求审批、自动审查或完全访问模式；模型运行和附件上传期间均可预设下一次执行的模型、推理强度、目录与权限。保存先校验目录并保留设置，普通发送或排队任务启动时应用，不改变当前回合的执行边界。每条本机排队消息保留提交时的执行设置。
- 中断当前任务，切回应用时刷新状态或尝试重新连接。停止入口独立于发送/排队按钮，保留草稿和附件时也能停止；刷新、改名、加载历史、新建和归档按具体操作与对话防重，互不锁住无关功能。
- ViewModel 保持屏幕旋转期间的连接、消息和草稿。
- 连接成功或回到前台时通过 SSH 自动检查应用更新；每个新版本只自动提醒一次并持久保存提醒历史，仍可从菜单手动检查更新或打开历史版本。
- 应用更新弹窗和历史版本列表的更新说明在内容较长时可在弹窗内部滚动查看，完整保留段落和换行，不会被固定高度裁掉；更新操作按钮仍保持可用。
- 新版本提醒只在聊天和对话列表页面显示，使用位于顶部的可访问性提示卡，支持淡入滑入、按系统可访问性建议时长自动消失、“查看”和忽略操作，不再遮挡工作区页面内容。
- 赤陶与暖米配色贯穿系统栏、启动背景、菜单和审批窗口；助手消息采用无气泡正文，用户消息使用不对称圆角卡片，执行过程以可展开的工单卡呈现。
- 发送与上传过程中可继续编辑草稿、添加或移除下一条消息的附件与上下文；成功确认只清理本次提交的内容，保留后来修改。每条消息最多添加 10 张图片，单张上限 10 MB，合计上限 30 MB。上传后，客户端通过 Codex 的 `localImage` 附件提交图片路径。
- 助手 Markdown 中的内嵌图片、工作区图片链接和 HTTPS 图片链接可在对话中预览；支持含中文、空格或 URL 编码的工作区路径。支持 PNG、JPEG、GIF、WebP、BMP、SVG、AVIF、HEIC 和 HEIF；图片读取限制大小、像素与缓存占用，并跳过普通 HTTP 图片链接。
- 聊天图片可打开原图预览，支持双指缩放、拖动、重置缩放和下载原图。
- 聊天中的同一张图片在文字路径、Markdown 链接和结构化附件同时出现时只显示一个图片来源；兼容 `file://`、编码空格和历史上传提示，保留不同签名链接和不同图片。单张用户图片在聊天中使用更大的预览尺寸，多张图片继续紧凑横向排列。
- 聊天顶部文件夹按钮、更多菜单及输入区附件菜单统一打开完整工作区页面；主要标签为文件、改动、媒体、网页和侧聊。文件点击后全屏预览，并可引用到聊天；返回预览来源标签或聊天，支持继续上次预览。
- 工作区新增「侧边聊天」，可从当前任务临时分出只读的 Codex 问答分支，继续追问任务背景和结果；侧聊禁止终端命令、工具调用、审批和子任务，最多保留最近 12 轮，连接变化后会明确提示并重新分支。
- 侧聊采用更紧凑的顶部说明入口、结束操作、任务问答空状态和圆角输入区；用户问题靠右显示，助手以无气泡正文显示，问答等待期间可继续编辑草稿。
- 工作区新增「浏览器」页，顶部提供网址输入框与打开按钮；未打开网页时显示操作提示，网页视图限制在内容区域。仅允许 HTTPS 地址，支持返回、刷新、加载状态和安全导航；可读取当前页面正文并作为网页上下文加入聊天，页面切换或关闭时不会把过期读取结果加入任务。
- 工作区「媒体」页汇总消息与工具结果中的图片和视频，支持查找更早媒体；按完整来源去重，显示缓存状态、已缓存图片缩略图或视频图标，可预览并保存到手机。
- 媒体条目显示图片/视频类型和可识别的文件格式，缩略图使用对应类型图标、文字和配色；网页页采用一体式地址栏，按状态提供打开、刷新和停止操作，标题旁可引用正文到聊天。
- 工作区「预览」页统一承接聊天、侧聊、文件页和媒体页中的链接，支持文件、目录、网页、图片及视频；可返回上一个预览，关闭后回到侧边聊天，最多保留 40 个预览导航记录。
- 文本文件可直接阅读和选择复制；Markdown 可切换阅读与源码模式，源码默认自动换行，也可在菜单中关闭换行并横向查看长行；文档内相对链接以文档自身目录或网址解析。正文预览上限为 192,000 个 UTF-16 字符单元，截断时提示，保存仍获取完整文件；文件支持保存到手机、分享及使用其他应用打开。
- 源码位置链接支持 `文件:行号`、`文件:行号:列号` 与 `#L行号` 格式，打开真实文件并定位对应位置；同一文件不同位置保留各自的预览导航记录，保存与分享使用真实文件名。
- HTTPS 远程文件支持受限重定向、超时、取消和 64 MB 下载限制；HTTPS 视频可直接播放，视频退出预览时释放播放器，失败可重试。内嵌聊天图片继续支持预览。
- 有内容的预览以全屏模式展示，隐藏系统栏和工作区标签，滑动屏幕边缘可临时显示系统栏，退出时恢复。系统返回键优先返回上一项预览；首项预览提供返回聊天入口，关闭预览回到侧边聊天。
- 窗口统一采用 edge-to-edge 布局，由 Compose 处理安全区域与输入法边距；全屏预览只切换系统栏可见性和显示行为，避免退出时重复叠加系统栏边距。系统栏使用与浅色主题相配的样式。
- 全屏图片支持 1～6 倍双指缩放、放大后拖动、双击 3 倍放大或复原，以及放大/复原按钮；拖动限制在实际图片边界内，原始比例下的单指滑动仍可交给附件画廊翻页。网页支持双指缩放；文本与 Markdown 预览支持 75%～250% 字号调整和复原。
- 聊天链接与 SSH 文件读取支持大文件存储目录 `/mnt/codex-storage`，可预览图片、文档和视频，并下载普通文件。支持中文、空格、URL 编码、同主机 file 链接及文档相对链接；链接解析和 SFTP 真实路径读取共用允许目录校验，大小和格式限制继续生效。
- 页面转场绑定各自的对话快照和页面标识，切换对话时保留对应聊天的可保存状态；退场页面不再抢占输入焦点或处理输入框返回动作。
- 聊天隐藏仅含空白文字的助手回复，保留协议占位以继续接收流式内容；图片、问题和工具卡片正常显示。
- 对话列表的连接状态、筛选、计数、空状态和卡片变化带有过渡动画。
- 新建对话入口位于列表标题右侧，模型选择位于聊天输入区，空白对话有独立起始页；异常作为时间线中的紧凑状态条显示在对应任务位置，可展开详情。
- 设置中的推理强度使用暖色滑块：拖动连续跟随、松手吸附档位，切换和恢复默认时滑钮与填充同步缓动。
- 对话首页支持按标题、模型或项目搜索和“全部/进行中”筛选；列表按运行中与最近对话分组，显示项目归属与最近任务状态，并在顶部提供新对话入口。
- 会话列表以标题、项目、时间和置顶/失败图标组成紧凑列表；正在进行的任务集中显示，默认展示一项，可展开全部。每条会话的“更多”菜单提供置顶、归档和删除，离线或任务运行期间禁用归档与删除。
- 对话可单独设置项目名称，和工作区目录分开保存；列表显示项目归属与最近任务状态，新任务显示尚未执行。
- 每次任务完成、失败或中断时，无论应用在前台还是后台，统一发送原生高优先级系统通知；点击打开对应对话，通知保留到点击、手动清除或打开该对话。系统顶部横幅需要允许通知及该分类的横幅提醒，可从“更多 → 任务通知设置”调整。
- 对话列表和侧边栏显示任务结果标记，打开对话或启动下一次任务时清除；后台补查也会更新标记并发送通知，同一任务的实时事件与补查结果去重，自动重连不清除未读标记。
- 离线时从本机缓存显示最近的对话和消息；连接恢复后再与服务器同步。

## SSH 应用更新

首次手动安装当前 APK。已安装 0.1.2 或更新版本时，可使用内置 SSH 更新；0.1.1 及更早版本需要先手动安装。后续必须使用同一签名和更高 versionCode。

版本清单位于 82 的 /home/ubuntu/codex/mobile-client/releases/latest.json。更新包通过当前 SSH 会话的 SFTP 通道下载，无需新增公网端口、网站或手机内保存中转 Token。下载与校验时可收起更新窗口，仍可进入历史版本；历史 APK 导出由 ViewModel 执行，关闭窗口后继续保存。

0.1.10 起，点击下载前会重新读取服务器的最新清单，直接下载当前最新版，无需逐版升级；下载完成后再次确认版本。点击安装前重新校验包大小、SHA-256、包名、版本号和签名，并再次读取最新清单；期间如果发布了新版，旧包会被删除，提示下载最新版。清单读取失败会清除旧版本提示和缓存安装包，必须重新检查后才能继续。已完整校验的更新包按版本和 SHA-256 保存在应用私有缓存中，弹窗关闭或进程重建后可恢复使用；缓存失效或清单变化时会自动删除并重新下载。大包通过受限的并行 SFTP 请求窗口传输，下载过程中仍持续校验大小和 SHA-256。

确认更新包后交给 Android 系统安装；首次需允许此来源安装应用，授权后返回应用再次点击安装。自动检查在应用连接或回到前台时进行，不在后台静默安装。已安装旧版的用户建议先用当前 APK 覆盖安装一次，以启用修复后的更新逻辑；不要卸载，以保留连接配置和私钥。

连接页、正在连接页面、公共菜单和更新弹窗提供“历史版本与恢复下载”。历史列表通过独立 SSH/SFTP 读取 `history.json`，无需 Codex app-server 连接成功；可选择版本、校验下载、保存 APK 到手机，或交给系统安装器。历史下载固定使用选中的版本，不会因出现新版而被替换。安装前仍校验大小、SHA-256、包名、版本和同一应用签名。

Android 通常禁止旧 versionCode 覆盖新版；历史原包可以下载并打开安装器，但应用无法绕过系统的降级限制。不要为降级贸然卸载：卸载会清除本机连接私钥、配置和缓存，服务器对话保留。

已有发布包可运行 `python3 codex/build-history-index.py --release-root <发布目录> --output <发布目录>/history.json` 建立历史清单；只收录固定 release 证书签名且包名正确的 APK。后续发布自动维护历史清单，不覆盖或清理旧 APK。

服务器端版本使用 `codex/build-release.sh` 构建签名 APK，再运行 `codex/publish-server-update.sh` 更新本机的自动更新包和清单。发布脚本会核对包名、固定签名证书、SHA-256 和递增的 versionCode，并原子替换 `latest.json`。不要用旧的 `codex/publish-update.ps1` 发布服务器 release 版本；它用于 Windows 上的调试包流程。

当前界面交互预览位于 codex/mobile-redesign-preview.html，为对应 Compose 布局的示例页面，不连接真实服务，也不代表安卓真机截图。旧的 codex/codex-mobile-preview.html 保留用于对照。

## 构建和检查

需要 JDK 17、Android SDK 35、Gradle 8.9。SDK 路径由 Android Studio 或 ANDROID_HOME 提供。示例：

    $env:JAVA_HOME='D:\JDK'
    $env:ANDROID_HOME='D:\AndroidSDK'
    .\gradlew.bat assembleDebug lintDebug --no-daemon --max-workers=1

### Release 签名

服务器 release 包使用长期 release 签名密钥，存放在 `~/.android/andri-release.jks`，Gradle 密码只在 `~/.gradle/gradle.properties` 中。0.1.17 及之后由服务器同一密钥签名的版本可以原位升级。密钥权限设为仅服务器用户可读；不要提交或发送 keystore。请另行制作受保护的离线备份，丢失后将无法继续原位更新。

如果要构建 release 变体并保持自动更新兼容，把原 keystore 路径、密码和别名写入本机 `~/.gradle/gradle.properties`，不要提交到仓库：

    ANDRI_RELEASE_STORE_FILE=<原 keystore 的绝对路径>
    ANDRI_RELEASE_STORE_PASSWORD=<本机填写>
    ANDRI_RELEASE_KEY_ALIAS=<原密钥别名>
    ANDRI_RELEASE_KEY_PASSWORD=<本机填写>

服务器 release 密钥已配置，无需再次生成。打包 ZIP 运行 `codex/build-release.sh`；发布到自动更新目录运行 `codex/publish-server-update.sh`。ZIP 内的 APK 可用于手动安装；同一证书签名且 versionCode 递增的版本也可通过应用自动更新。若上架 Google Play，应另行使用 Play App Signing。

可用 `ANDRI_RELEASE_OUT_DIR` 指定 ZIP、安装说明和校验文件的输出目录；服务器大文件产物优先写入已核验挂载可用的远端存储。此参数不改变 APK 构建目录或自动更新发布目录。

Linux 打包脚本还需要 Python 3 和系统 ICU 库。打包时会导出检查用类路径，再通过 `codex/checks/regex_icu_check.py` 验证编译后的可视化预览及图片路径正则是否兼容 ICU；失败时不生成发布 ZIP，避免只在桌面 Java 上通过的正则被发布。

检查脚本位于 codex/checks。当前 Windows/JDK 17 对中文路径的 Gradle 测试 worker 参数文件存在编码问题，因此使用以下脚本编译检查后直接运行 JUnit：

    .\codex\run-checks.ps1

带真实 SSH/模型调用的检查需要显式提供本机密钥路径。测试只从该路径读取密钥，不会把密钥复制到项目：

    .\codex\run-checks.ps1 -SshKeyFile 'C:\Users\35243\.ssh\id_ed25519'

真实调用会创建少量检查对话；工具检查仅执行带 MOBILE 标记的 printf/sleep 命令，不修改项目文件。构建、连接诊断和原始检查日志均放在 codex。

## 验证边界

APK 构建、Android Lint 和 JVM 上使用同一客户端代码的真实服务器调用，不等于安卓手机上的完整验收。当前没有连接实体手机或配置可用模拟器，仍需要在目标手机确认安装启动、密钥导入、输入法、后台切换和网络切换。

应用尚未实现语音和远程推送；Git 改动视图提供只读文本差异。Android 杀死应用进程后，重新打开时自动恢复连接和上次对话；服务器服务独立运行。
