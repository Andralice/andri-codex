本次更新（相对 0.1.88）：

- 输入框上方为待发送图片附件提供顺序引用按钮（`@1`、`@2` 等）；点击后在光标处插入对应标记，若有选区则替换选区，并自动补足必要空格、展开输入区及调出键盘。
- 普通发送和排队发送的任务内容现在为每张手机图片附上相同编号和对应项目 `codex/inbox` 路径，便于在任务描述中明确指向某张图。
- 草稿状态同步时保留当前光标/选区位置，不再将编辑位置强制移到文本末尾。
- 执行时间线遇到线程已报告运行、但活动回合 ID 尚未同步的短暂状态时，以最新执行回合作为进行中分组；运行中摘要若包含失败步骤会显示提示。
- 执行记录明细项采用稳定 Compose key，降低列表展开和状态更新时条目状态错位的风险。
- 工作区文本和 Markdown 源码预览默认关闭自动换行，长行打开后可横向查看；仍可从菜单切回自动换行。
- 手机对话转发网关源码恢复对 `thread/resume.initialTurnsPage` 的原样转发，移除省略该可选参数的兼容分支及临时诊断探测脚本。该服务端源码变更只随源码提交，本次 APK 发布不部署或重启网关服务。
- 版本升级为 0.1.89（versionCode 90）。
