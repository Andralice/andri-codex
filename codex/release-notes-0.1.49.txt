本次更新（相对 0.1.48）：

- 助手 Markdown 图片和工作区图片新增 SVG、AVIF、HEIC、HEIF 格式支持；工作区读取端扩展对应格式校验，手机端使用 SVG 与系统图片解码器渲染。
- 保留图片来源与解码安全限制，包括文件大小、源图尺寸、输出像素和缓存占用上限；不支持的格式或无法解码的图片继续显示可重试的错误状态。
- 改进助手 Markdown 加粗标记的空格纠正：把错误放在闭合标记前的空格移至标记外，使常见生成文本正确显示粗体。
- 新增 Android SVG 解码依赖，README 更新支持的图片格式和版本信息。
- 版本号升级为 0.1.49（versionCode 50）。
