本次更新（相对 0.1.61）：

- 新增工作区 HTML/HTM 网页交互预览，支持 JavaScript、网页存储和双指缩放，可在「网页预览」与「查看源码」之间切换；原有保存到手机、分享和其他应用打开入口继续保留，源码模式可调整字号。
- 聊天及侧边聊天中的可视化引用标记转换为「打开交互预览」链接，支持项目工作区和大文件区的 HTML 文件；代码示例中的引用、无效数据及不支持的目标保留原文。
- 将 HTML 片段所需的配套样式和浏览器交互运行脚本打入 APK，片段自动补齐网页结构、移动端 viewport 和样式；完整 HTML 网页保留原结构。部分图标、提示浮层相关组件通过 HTTPS 加载外部脚本，需要客户端能访问这些资源。
- HTML 预览独立读取完整文档，上限为 8 MB，避免普通文本预览截断造成脚本或样式缺失；超过上限给出提示，可保存后打开。
- 本地 HTML 使用独立预览来源，经 SSH 加载文档目录内的 CSS、JavaScript、图片和字体资源，限制链接解析中的目录越界；禁用 WebView 直接文件与内容访问、弹窗和混合内容。页面内链接继续交给统一工作区预览，关闭时销毁 WebView，加载错误可见。
- 新增普通文字图片路径识别：项目工作区和大文件区的图片路径转换成带文件名的「图片附件」链接，并复用图片预览；路径去重，支持绝对路径、相对路径及 URL 编码，保留原有 Markdown 图片和视频展示。
- 新增交互预览回归检查，覆盖标记转链接、代码示例保留、特殊文件名、完整 HTML 与片段包装、超过文本预览长度的 HTML、8 MB 限制、同目录资源解析和越界拒绝。
- 版本升级为 0.1.62（versionCode 63），README 同步更新。
