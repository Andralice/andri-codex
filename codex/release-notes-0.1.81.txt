Andri Android 0.1.81（versionCode 82）
对比上一发布版本 0.1.80（versionCode 81）：

1. 在线网页：HTTPS HTML/HTM 链接直接进入内置浏览器，不再先下载为文件；页面内部的跳转、交互和浏览器返回沿用正常网页流程。
2. 聊天网页入口：识别 Markdown 中的 HTML 文件链接、在线 HTML 链接和工作区裸路径，显示可点击的网页卡片；同一页面去重，代码示例和带源码行号的链接不生成卡片。
3. 项目 HTML 预览：增加加载百分比及进度条、刷新网页按钮；刷新会重新读取 HTML 并重建预览，从服务器加载当前页面资源。
4. 加载失败提示：HTML 预览显示主页面错误、HTTP 状态和部分本地资源加载失败提示；内置浏览器新增网页加载进度条及主页面 HTTP 错误提示。
5. 文档：说明网页入口、本地 HTML 预览、源码切换及后端服务要求。

使用方式：点击聊天中的网页链接或 HTML 网页卡片；也可在项目文件浏览器中点击 HTML/HTM 文件。
本地页面沿用同目录下图片、CSS、JavaScript 资源读取能力；在线浏览沿用 HTTPS 策略。需要后端的页面仍需对应服务运行。
验证：链接路由、卡片识别、代码与路径边界的自动检查；完整单元检查、Android lint 和 ICU 正则兼容性检查。未连接安卓真机，未验证真机 WebView 显示效果。
