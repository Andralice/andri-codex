- 修复聊天 Markdown 链接的点击处理，保留长按选择文字。工作区文件链接打开文件预览，目录链接打开目录浏览；相对链接以当前对话工作区为基准，支持绝对路径、file 链接以及含中文、空格或 URL 编码的路径。

- 图片预览与链接点击共用工作区路径解析，规范化绝对路径和点击时解析出的相对路径，拒绝指向工作区外的路径及远程主机的 file 链接。HTTPS 图片地址保留查询参数，并对非 ASCII 字符做 URL 编码。
- 扩充图片链接回归检查，覆盖原图路径、目录链接、工作区边界和图片与网页的分流。版本升级为 0.1.52（versionCode 53），README 同步更新。
