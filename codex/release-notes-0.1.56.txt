本次更新（相对 0.1.55）：

- 工作区新增统一「预览」页。点击主聊天、侧边聊天、文件列表和媒体列表中的链接，以及 Markdown 图片和「查看原图」入口，在工作区打开文件、目录、网页、图片或视频，替代原先分散的文件、目录和媒体弹窗；预览支持返回上一项和关闭，关闭后回到侧边聊天。
- 预览导航按当前对话保存，连续相同目标不重复入栈，最多保留最近 40 个目标；再次点击链接会自动切换到预览页，工作区的可保存状态和各预览的阅读状态分别保留。
- 新增文本文件阅读，包括常见代码、配置、日志、字幕等格式；Markdown 支持阅读模式与源码模式切换，源码可选择复制和横向滚动。文档中的相对链接以文档所在目录或网址解析，支持中文、空格、URL 编码和文件名中的 # 等字符。
- 文本预览最多读取开头 192,000 个 UTF-16 字符单元，不截断 emoji 的代理对；内容过长时提示，保存可获取完整原文件。文件支持保存到手机、分享、显示大小和错误重试；不支持直接阅读的格式可交给手机上的兼容应用打开。
- 新增 HTTPS 远程文件下载，限制 64 MB、连接与读取超时及重定向次数，拒绝跳转到非 HTTPS 地址；下载可响应取消，失败时清理未完成文件。原工作区路径和链接协议边界继续生效。
- 预览页可继续浏览目录并打开子目录或文件；网页复用现有 HTTPS 浏览器，图片继续使用原图预览组件，媒体入口保留内嵌 data 图片支持。内嵌图片数据不写入页面恢复状态，避免恢复状态过大；页面重建后可从媒体列表重新打开。
- 统一视频播放器支持 HTTPS 视频和已下载的服务器原画质视频，按视频尺寸调整比例，提供播放控件、失败提示和重试；退出时停止并释放播放资源。
- 新增预览回归检查，覆盖链接分类、相对路径、中文与特殊文件名、远程链接查询参数和片段、工作区与协议边界、内嵌图片、长文本与 emoji 截断，以及明文下载拒绝。
- 版本升级为 0.1.56（versionCode 57），README 同步更新。
