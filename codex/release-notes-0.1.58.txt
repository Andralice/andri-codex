本次更新（相对 0.1.57）：

- 客户端文件访问新增大文件存储目录支持，聊天中的图片、文件和视频链接不再因产物保存在大文件区而被工作区路径限制拦截；通过 SSH/SFTP 读取后，可使用现有预览、原图保存、文件保存及视频播放功能。
- 聊天链接解析、Markdown 图片识别和统一预览支持大文件区绝对路径、同主机 file 链接及 URL 编码路径，保留中文文件名、空格和预览导航往返后的目标一致性。
- 大文件区文档中的相对图片、视频、文档和父目录链接按文档所在目录解析；大文件区根目录即使没有末尾斜杠也识别为目录，可继续使用目录预览。
- 新增共享文件读取目录规则，由聊天链接解析及 SFTP 普通文件、图片、视频读取共用。路径先规范化，SFTP 读取在服务器 realpath 解析后再次校验；拒绝允许目录之外的路径、相似前缀的相邻目录、越界跳转、空字符及其他主机的 file 链接。
- 文件类型、普通文件检查、图片内容检查、下载完整性及原有大小限制继续生效：工作区或大文件区普通文件最大 512 MB，图片最大 10 MB，视频最大 1 GB。
- 新增大文件区回归检查，覆盖中文图片的多种链接写法、Markdown 图片识别、预览往返、文档相对链接、根目录识别、目录内路径规范化及越界拒绝。
- 版本升级为 0.1.58（versionCode 59），README 同步更新。
