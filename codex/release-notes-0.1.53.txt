本次更新（相对 0.1.52）：

- 新增独立工作区页面。点击聊天顶部文件夹按钮或在消息区左滑进入，右滑、点击返回按钮或按系统返回键回到聊天。切换带滑动动画，返回时保留聊天滚动位置和可保存的界面状态。
- 工作区的「文件」页支持浏览当前项目目录、返回根目录或上一级、刷新列表、预览文件，以及把文件加入当前聊天上下文。
- 工作区的「改动」页支持刷新和查看 Git 改动，内容可选择复制、横向和纵向滚动；过长时会提示截断。文件与改动页都显示连接、加载、空列表或读取失败等状态。
- 修复带 SVG 元数据的 PNG 被误识别成 SVG 而无法预览的问题。聊天解码和服务器图片读取共用 PNG 与 SVG 格式识别；SVG 需为文档根元素。
- 新增图片格式回归检查，覆盖含 SVG 元数据的 PNG、带 XML 声明的 SVG 和非 SVG 根元素。版本升级为 0.1.53（versionCode 54），README 同步更新。
