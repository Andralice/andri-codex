本次更新（相对 0.1.47）：

- 任务完成、失败或中断时，无论应用在前台还是后台，都发送可持续保留的高优先级系统通知；点击通知进入对应对话，打开对话或手动清除后解除提醒。通知使用专用小图标和振动提示。
- 新增“更多 → 任务通知设置”，可打开应用通知或任务横幅分类设置；Android 13 及以上连接后会请求通知权限，并提示未授权时的开启路径。
- 对话列表和侧边栏显示最近任务结果未读标记，状态在应用重启后保留，进入对话后清除；后台补查也会恢复结果提醒，并对同一任务的实时通知与补查通知去重。
- 改进聊天及工作区图片加载：显示加载进度和具体失败原因，支持手动重试；HTTPS 图片加载失败时可以复制链接，图片列表按来源稳定复用加载状态。
- 改进原图保存：保存过程显示进度、成功或失败反馈，并防止重复触发；系统权限流程完成后继续保存到相册，预览页面反馈避开系统安全区域。
- 工具追问在存在选项时默认折叠自定义回答输入；已有自定义内容会自动展开，仍可填写多行答案。
- 改进 Git 改动审阅：从所选目录解析实际仓库根目录，显示对应仓库路径，并返回更具体的 Git 错误信息。
- 更新任务结果状态模型及回归检查，覆盖实时与后台结果去重、已读状态保留、通知权限未授予和进行中状态处理。
- 版本号升级为 0.1.48（versionCode 49），README 同步更新。
