本次更新（相对 0.1.87）：

- 工作区源码预览增加轻量语法着色，支持 Kotlin/Java、JavaScript/TypeScript、Python、Shell、JSON、XML/HTML/SVG、CSS/SCSS、SQL、YAML/TOML、Go、Rust 和 C/C++；覆盖关键字、字面量、字符串、注释、数字、类型、函数、注解和属性等常见 token。
- 执行时间线的命令输出按读取命令中的文件扩展名或输出内容推断语言并着色；无法识别为源码的命令输出按 Shell 着色。
- 执行时间线长输出限制最大显示高度并可纵向滚动，增加滚动位置指示，避免长结果挤占整个聊天页面。
- 服务器任务管家加入有界的只读证据采集，记录命令类别、退出码、文件变更数量，并在工作区边界内有限检查测试报告和被提及的产物；明确区分助手汇报、工具观察与有限本机检查，不把这些结果冒充完整验收、远端部署核验或真机验证。
- 后台审查改用持久、隐藏于普通会话列表的 reviewer fork；保存上下文指纹和每日审查记录，根据相关会话上下文复核任务，并在上下文变化、过期问题或用户补充答复后重新审查。
- 需要用户决定时改用 Codex 原生问题卡。回答只从与对应事件和回合匹配的 session JSONL 原生提问调用及工具结果读取；服务通知、助手文字、exec 输出不能作为用户授权。
- 原生问题可在服务重启和手机重连后恢复；过期问题会撤回，真实回答只绑定原事件处理，自由文本作为该事件的补充信息重新审查，不会改变全局偏好。
- 管家 MCP 管理接口拒绝服务通知回合修改管理偏好；事件接口和进度报告增加证据等级、问题状态及验收边界说明。
- 手机对话转发网关兼容不支持 `thread/resume.initialTurnsPage` 的已安装 app-server：转发恢复请求时省略这一可选参数，让客户端通过 `thread/turns/list` 获取初始历史，避免已载入会话恢复失败；增加对应的故障探测脚本。
- 更新 README 和任务管家文档，并增加对应的本机检查及协议探测脚本源码；本次没有运行测试套件。
- 版本升级为 0.1.88（versionCode 89）。

任务管家服务器改动随项目源码提交；本次 Android APK 发布不会部署、启用或重启服务器任务管家服务。
