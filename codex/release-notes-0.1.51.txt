本次更新（相对 0.1.50）：

- 助手回复里的普通 Markdown 图片文件链接也能直接显示预览，支持工作区的相对路径、绝对路径和本机 file 链接。路径含中文、空格或 URL 编码时按实际文件名读取，同一图片以不同链接写法出现时去重。
- 统一用 Markdown 解析器识别内嵌图片、引用式图片和 HTTPS 图片链接，保留 HTTPS 链接的查询参数；代码块中的示例、普通文档链接和工作区以外的绝对路径不生成图片预览。
- 后台任务补查与聊天页面共用图片链接解析；服务器文件读取与 HTTPS 图片检查共用支持格式列表，减少前台和后台识别不一致。
- 新增图片链接回归检查，覆盖中文路径、带空格的 URL 编码路径、重复链接、引用式图片和代码块排除。版本升级为 0.1.51（versionCode 52），README 同步更新。
