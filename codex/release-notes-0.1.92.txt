本次更新（相对 0.1.91）：

- 新建对话时向 app-server 注册手机工作区动态工具：Codex 可读取手机工作区当前选中的标签、页面路径/网址、已打开标签及项目目录，也可在手机工作区新开标签并打开工作区文件、目录或网页。打开动作由手机确认完成后再返回工具结果；请求来自非当前对话、页面地址无效或打开超时都会返回失败。
- 对尚未注册动态工具的既有对话，向模型上下文提供当前工作区状态，并提供通过 SSH/SFTP 受限动作邮箱打开页面的兼容方式；请求文件使用项目 `codex/.mobile-workspace-control` 私有目录、随机 UUID 文件名、严格的路径/类型/大小校验，并在处理后删除。普通发送与排队任务均支持；取消或任务结束时清理邮箱文件。
- 工作区网页浏览器接受有效的 HTTP 和 HTTPS 地址；工作区预览页面及文件链接下载也支持 HTTP，包含重定向后的 HTTP(S) 地址校验。
- 为支持 HTTP 网页及其 HTTP 子资源，Android 应用允许明文网络流量，两个工作区 WebView 允许混合内容；安全浏览仍保持启用，浏览器导航仍拒绝无效地址和带用户信息的 URL。
- 版本升级为 0.1.92（versionCode 93）。
